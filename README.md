# 📊 Simulador de Investimentos em Fundos Imobiliários (FIIs)

## 📖 Sobre o Projeto

Este projeto foi desenvolvido como parte do desafio prático da DIO com o objetivo de aplicar conceitos de Excel na criação de uma ferramenta de simulação de investimentos em Fundos de Investimento Imobiliário (FIIs).

A planilha permite que o usuário realize projeções financeiras de forma simples e automática, auxiliando na tomada de decisões sobre investimentos de longo prazo.

## 🎯 Objetivos

- Aplicar fórmulas e funções avançadas do Excel.
- Criar uma ferramenta prática para simulação de investimentos.
- Automatizar cálculos financeiros.
- Desenvolver habilidades de análise de dados e modelagem financeira.
- Documentar um projeto técnico utilizando GitHub.

## 🛠️ Funcionalidades da Planilha

A ferramenta permite:

✅ Definir o valor do aporte mensal;

✅ Informar o período de investimento;

✅ Configurar a taxa de rendimento mensal;

✅ Calcular o valor total investido;

✅ Projetar o patrimônio acumulado ao longo do tempo;

✅ Estimar os dividendos mensais gerados pelos investimentos;

✅ Visualizar cenários para apoio à tomada de decisão.

## 📈 Indicadores Calculados

A planilha realiza automaticamente os seguintes cálculos:

- Valor total aportado;
- Patrimônio acumulado;
- Rentabilidade estimada;
- Dividendos mensais projetados;
- Evolução do patrimônio ao longo do período escolhido.

## 🚀 Como Utilizar

1. Faça o download do arquivo `Simulador_FII.xlsx`.
2. Abra a planilha no Microsoft Excel.
3. Informe:
   - Valor do aporte mensal;
   - Prazo de investimento;
   - Taxa de rendimento estimada.
4. Analise os resultados gerados automaticamente.
5. Compare diferentes cenários para planejar seus investimentos.
